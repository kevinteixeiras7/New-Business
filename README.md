# Seventy7 New Business

New business pipeline and opportunity radar for Seventy7 Client Services and New Business.

- Hosted on GitHub Pages. Data, Google sign-in and the daily news radar run on Firebase.
- Until `FIREBASE_CONFIG` at the top of `index.html` is filled in, the page runs as a preview with sample data.
- Never commit tracker data or seed.json here: this repo is public. Client data lives only in Firestore, behind the security rules.
